# Ceylon Odyssey Travels

A responsive single-page tourism website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Before publishing
1. In `script.js`, replace `WHATSAPP_NUMBER` with the real WhatsApp number in international format without `+` or spaces.
2. In `index.html`, replace the demo phone number and email address with the real business contact details.
3. Replace the sample social `href="#"` links with the company's social profiles.
4. The enquiry form opens the visitor's email application using a `mailto:` link. For server-side submissions, connect a form service or backend.
5. Images and fonts are loaded from Unsplash and Google Fonts, so an internet connection is needed for those assets.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js` and this README to the repository root. In GitHub, open **Settings → Pages**, choose the deployment branch and `/ (root)`, then save.
